Pasting images into the message box

Three ways to show pasted images, each live: copy any image (a screenshot with ⌘⌃⇧4 works) and press ⌘V in a box, drop a file on it, or use "Paste a sample". Enter sends.

A. Inline reference

Pasting drops [Image #3] where the cursor is, so you can say which image you mean. Hover it to see the image, click to open it full size. With the keyboard, putting the cursor right next to a token shows the same preview, ⌘Y opens it, and Backspace removes it whole. Numbers count up per tab, so "#1" means the same image to you and the agent for the whole conversation.

Token
Try: click after the token and press Left, then ⌘Y

B. Tray above the text

Images collect as thumbnails at the top of the box and the text stays plain. Hover a thumbnail for a bigger preview. Up at the start of the box moves into the tray, where Left Right move, Space opens, Backspace removes and Down or Esc goes back to the text.

C. Both: tokens in the text, numbered tray above

The tray shows everything attached at a glance, and the tokens say where each image belongs. Hovering either one lights up the other, and removing one removes both. Sent messages show the thumbnails above the bubble with their numbers.

A suits
  • Talking about images: "before [Image #1], after [Image #2]"
  • Densest: the box doesn't grow
  • Same convention as Claude Code, which many agents already expect
B and C suit
  • Pasting several images at once without describing them
  • Seeing what's attached without hovering
  • B is simplest to build: no styled text inside the box

Edge cases

Shown with the inline token, but they work the same with the tray.

The agent doesn't take images

ACP agents say whether they accept images (promptCapabilities.image). Knowing before sending beats an error after: the token turns red and sending waits until it's removed.

Dropping a file

Dragging images from Finder works like pasting. The box shows where they'll land. Drag a real file onto any box above to see it there.

Something you were typing

A big screenshot

Retina screenshots are large. Anything over the size limit is scaled down before it's sent, and the preview says so. Models scale them down anyway, so this only saves time on the wire.

Many images

Past a few, the inline tokens stay compact and a count in the footer says how many are attached, so nothing goes unnoticed.

Keys and settings

Every action gets a rebindable key and a palette entry, as usual.

ActionDefaultWhat it does
Paste⌘VImages on the clipboard become attachments. Text pastes as plain text.
Attach image...⌘⇧AOpens a file picker, for when the image is a file and Finder isn't handy. Also in the palette.
Open image⌘YOpens the image next to the cursor, or the focused thumbnail, full size. Like Quick Look. Left Right step through the message's images, Esc closes.
Remove imageBackspaceNext to a token it removes the whole token. In vim normal mode, x on a token does the same.
Open images in messageoIn the transcript, opens the images of the message you're on.
# ~/.config/tectr/dsk.toml
[composer]
images = "inline"           # inline | tray | both
image_preview = "hover"     # hover | hover_and_cursor | off
image_max_edge = 2000       # px on the long side; bigger pastes are scaled down before sending
