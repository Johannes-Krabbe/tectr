Topic status icons

Working moves, done is green until you've seen it, then it goes gray. Everything below is live: open topics in the sidebar, switch options, and the whole page follows.

In the sidebar

Click a topic, or focus the sidebar and use j k to move and Enter to open. Moving focus doesn't mark anything read, opening does. u toggles unread on the focused row. Working topics finish on their own after a few seconds.

Today and proposed

Only working and done change. Waiting, failed, idle and offline keep their shapes and colors, and every icon is still one color on any surface.

How it should behave

What counts as read
A session turns unread when a turn finishes. Opening its topic in a focused window marks it read. Focus moving through the sidebar doesn't count, only the topic shown in the main panel. If you're already looking at the topic when it finishes, you get the green check for about a second and then it fades. If the window isn't focused, it stays green until you come back.
Topic order
A topic shows its most urgent session: waiting, failed, unread done, working, read done, idle, offline. Today working comes before done. An unread result is something for you to do and working isn't, so it moves up. The cost: a topic with one tab still working and one finished shows the green check, not the spinner.
Failed
No read state. It stays red until you retry or close the tab, because it's broken, not new.
Where it lives
Read state is about you, not one window, so it goes in the daemon next to the session: an unread flag set when a turn ends, and a mark_read / mark_unread action. Read it on the phone and it goes gray on the desktop, and the push relay can use it for badges later. Keeping it in each client would be smaller but every client would disagree.
Keys
New actions Mark unread and Mark all read, each with a rebindable key and a palette entry.
Motion and speed
One CSS rotation per working icon, on the compositor, with no JavaScript per frame. The animation only exists while the state is working. Every spinner is pinned to the document timeline (animation.startTime = 0), so they all turn in lockstep no matter when a row appeared. Reduced motion, from the system or a new appearance.status.animate setting, shows the arc standing still, which still reads differently from idle.
Tokens and files
status.done becomes green (dark #5cc99a, the same as status.online; light #16875f). New status.done-read aliases text.tertiary. working.svg becomes a faint ring plus an arc, rotated in CSS. New done-read.svg is the outline check. iOS rotates the arc layer with a SwiftUI animation.
